# 元气骑士 · 轻量版

一个用原生 HTML5 Canvas 手搓的《元气骑士》复古轻量版：**没有账号、没有养成、没有日常，打开就是一局地牢**。
整个游戏 0 依赖、0 构建、0 资源文件（所有像素图都是代码画出来的），双击 `index.html` 就能玩。

```
soul-knight-lite/
├── index.html          # 入口
├── css/style.css       # HUD / 菜单（逻辑分辨率 384x216，整体倍缩放到窗口）
├── js/
│   ├── core.js         # 常量、数学、输入、WebAudio 音效合成
│   ├── art.js          # 像素精灵 + 程序化场景绘制、房间地面预渲染
│   ├── weapons.js      # 13 把武器数据 + 开火 / 挥砍 / 光束判定
│   ├── entities.js     # 玩家、4 个角色、6 种杂兵、3 个 BOSS、子弹、掉落
│   ├── dungeon.js      # 楼层拓扑生成、门、障碍布局、刷怪点
│   └── game.js         # 主循环、相机、房间锁定、楼层推进、HUD、菜单
└── tools/              # 无头 Edge + CDP 的自动化截图/回归脚本（开发用，玩不需要）
```

## 怎么玩

用浏览器直接打开 `index.html`（Chrome / Edge 都行，推荐全屏）。

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` / 方向键 |
| 瞄准 | 鼠标 |
| 攻击 | 鼠标左键（按住连发） |
| 冲刺 | `空格`（有无敌帧，刺客两段） |
| 换武器 | `Q` / `1` `2` / 滚轮 |
| 拾取 · 买 · 互动 | `E` |
| 暂停 | `ESC` |
| 性能读数 | `F3` |

选人界面点击卡片选择，`Enter` 或点「出发」开始。

## 一局是什么样的

**三层地牢，一命通关。**

每一层是一张随机生成的房间图（10～13 间，其中 5 间以上是战斗房）：从一个安全屋出发，一路打过去，
找到最深处的 **BOSS 房**，砍完 BOSS 会掉一个专属宝箱 + 传送门，开完箱踩传送门下一层。三层打完通关。

右上角有**小地图**：整层结构 + 每间房的图标（骷髅=BOSS、箱子=宝箱、金币=商店、十字=祭坛、剑=精英），
当前房间白框标出，下面是图例。

- **战斗房**：进房即关门，清光小怪门才解锁。**每间战斗房清完保底掉一口宝箱**（里面必出血瓶 / 能量 / 武器之一）+ 一堆金币。
- **精英房**：一只精英怪 + 一堆小弟，精英**必掉武器**。
- **宝箱房**：三口宝箱。
- **事件房**：铁匠 / 雕像 / 赌徒 / 许愿井，花金币换东西。
- **商店房**：四个货架——大血包 10 / 能量水晶 8 / 随机武器 24 / **天赋券 40**（直接换一次三选一）。
- **天赋祭坛**：紫色浮空符文，走过去按 `E` 白拿一个天赋（每层必有一个）。
- **BOSS 房**：掉**该 BOSS 专属的传说武器宝箱**，另外再免费选一个天赋。

**打 BOSS 会回满护甲 + 回 2 血 + 补能量**，所以别怕拼。

## 天赋（肉鸽成长）

**正常获取途径就和原作一样：每清空 4 间房，免费三选一一次。** 另外过 BOSS 也给一次，祭坛房走过去直接白拿一次。

金币可以在这里花：天赋界面有「换一批」，15 金币起、每刷一次更贵，用来赌一个更合体系的组合。

共 **23 个机制型天赋**（几乎没有纯数值的），可以叠加：

| 分类 | 天赋 |
| --- | --- |
| 弹道 | 子弹弹射（撞墙反弹）、暴击穿透、子弹分裂（命中溅射两侧）、散弹增加（弹丸+2）、重弹头（变大+击退）、子弹减速（敌方子弹变慢 + 吸物范围变大） |
| 近战 | 近战扩大、近战反弹（把敌人子弹打回去变成你的）、旋风斩（近战击杀触发环形斩） |
| 生存 | 破甲冲击（护甲碎了放冲击波）、破甲修复（碎了立刻回 50%，30s 一次）、疾步生甲（移动时回护甲）、刺盾（免疫身体碰撞） |
| 击杀 | 尸爆（死亡爆炸，会连锁）、击败回血、击败回蓝、愈战愈勇（连杀叠攻速） |
| 暴击 | 血怒（越残越猛）、满血暴击（打满血敌人必暴）、雷暴（暴击落闪电） |
| 经济 | 商店半价、贪婪（金币+60%）、金盾（每 100 金币 +1 护甲上限） |

真正的构筑感来自组合：
**子弹分裂 + 暴击穿透 + 雷暴** = 一发子弹在怪堆里连锁炸开；
**近战反弹 + 近战扩大 + 旋风斩** = 站着不动把弹幕全打回去；
**破甲冲击 + 疾步生甲 + 金盾** = 用护甲当护盾反复爆。

## 敌人有前摇了，近战能玩了

这是这一版最重要的改动。之前小怪是**贴着就掉血**，等于逼你只能用远程。现在：

- 每个会近战的小怪都有 **0.42 秒起手**：头顶红色感叹号 + 地面红环 + 朝向扇形，**起手期间几乎不动**，
  出手那一帧才判定伤害。
- **被近战武器打中会进 0.3 秒硬直**，完全停手、不能移动，白闪一下。
- 近战武器**射程全线加强**（短剑 27→31、太刀 31→35、战锤 35→39…），比小怪的攻击距离更远。
- 挥砍照样能打掉/弹回子弹。

结果：拿着短剑冲进 4 只小怪里，卡着起手节奏挥砍，可以**零伤清房**（自动化测试就是这么打的）。

## 武器手感：每把都不一样

**蓄力型**（猎弓 / 精准步枪 / 激光枪 / 熔岩重炮）：按住左键蓄力，身上会转一圈蓄力环。
满蓄自动放，伤害最高 ×2.4；提前松手放弱一发。想打爆发就得站定，和"边跑边泼子弹"的枪完全是两种节奏。

**近战三连击**：连续挥砍是三段，第三段是收招重击（伤害 ×1.7、范围 ×1.3、击退 ×1.6、硬直 ×1.7），
命中还有顿帧 + 额外火花 + 低频音效，打起来有"咔"的收招感。停顿 0.85 秒连击重置。

**霰弹枪**：6 发扇形，子弹只飞 0.42 秒（≈120px），逼你贴脸。
**冲锋枪**：0.085 秒一发，靠射速和能量上限吃饭。
**弹跳枪**：子弹撞墙反弹 3 次，狭小房间能把整个屋子扫一遍。

近战有个关键机制：**挥砍会打掉范围内的敌方子弹**，配「近战反弹」天赋还能打回去。

**换武器不会吞掉旧武器**：新枪捡起来，旧的直接掉在你脚下。

**强度一眼可见**：走近地上的武器会弹出对比浮窗 ——
`单发 5×6 / DPS 40 / ▲ +21% / 耗能 2 · 0.75s/发`。

- **红格 = 生命**，掉光了就死。

## 三个 BOSS（打的是走位）

招式都带**地面预警区**：红色圆圈由内向外填满，填满那一刻才判定伤害 —— 躲开就零伤。
冲锋是红色长条预警带；环形弹幕有的会**故意留缺口**，得看准缝隙穿过去。

1. **史莱姆王**（苔洞）：跳砸（地上一个会填满的红圈）→ 落点砸地 + 环形弹；扇形弹幕中间留缝；召唤小史莱姆。
2. **熔岩守卫**（熔岩）：红色长条预警 → 直线冲锋；四连落点轰炸（每次都砸在你当前位置附近）；带缺口的环形弹。
3. **霜语巫妖**（霜殿）：瞬移到你身边放缺口环弹；三颗慢速**追踪**冰球（必须绕圈跑）；范围冰爆预警。

## 几个手感上的小设计

- 命中会有一瞬间的「顿帧」（hitStop）+ 屏幕抖动 + 白闪，近战命中尤其明显。
- 子弹每帧分步推进，所以再快也不会穿墙/穿怪。
- 门锁的判定留了余量（要走进房间 2.4 格才锁门），另外每帧都有一个"卡进墙里就把你拽出来"的兜底，
  所以冲刺进 BOSS 房不会再被门夹住。
- 掉落的金币会自动被吸过来；血包满血时不会浪费。
- 冲刺有无敌帧，可以穿弹幕，但撞墙会停。

## 卡顿 / 卡死救急

游戏内按 **F3** 可以在左下角看到实时帧率和对象数量，排查很直观。

代码里已经做了这些兜底：

- 自动降画质：帧率持续低于 42 就会自动砍粒子、关暗角；回到 52 以上自动恢复。
- 帧率上限 ~72fps（高刷屏不会白烧一倍性能）。
- HUD 限流到 15Hz 更新，不再每帧写 DOM。
- 切到后台自动暂停。
- 主循环有 try/catch：万一某帧抛异常不会每帧刷屏把浏览器拖死，连续出错会自己停下来。
- 不再使用 `ctx.filter`（Chromium 里会强制走软件滤镜路径，是常见的性能/崩溃陷阱）、
  舞台也不再叠 `border-radius` + `overflow:hidden` + 大模糊阴影（会让合成器每帧重新栅格化整个放大图层）。
- 音频节点播完立刻 `disconnect()`，并有每帧发声预算。

如果还是卡，先试：**换 Chrome / Edge 打开**、关掉浏览器扩展、把窗口缩小一点，
然后把 F3 的读数告诉我（FPS 数字、是否出现 `low`）。

## 开发 / 调试

`tools/` 里是无头 Edge + CDP 的自动化脚本（需要 Node 22+ 和本机 Edge）：

```bash
node tools/cdp.js title char play boss flow verify
```

会跑一遍场景、打印状态断言、把截图写到 `shots/`，并收集 console 错误。
正式玩的时候完全不需要这些。
