# 60秒：地堡余生

致敬《60 Seconds!》（Robot Gentleman）的**原创同人小游戏**，非官方作品。
纯前端、零依赖、不联网，双击 `index.html` 即可运行。

👉 **直接双击 `index.html`**，用浏览器打开就能玩（推荐 Chrome / Edge / Firefox）。
想发给别人单文件的话，跑 `node dev/build.js` 会打包出一个自包含的 HTML。

---

## 玩法

### 第一幕：60 秒
防空警报响了，你只有 60 秒。

- **WASD / 方向键**：跑过自家房子（每局房间布局、家具、物资位置都随机）
- **空格**：按住抓取物资（约 0.4 秒一件）；碰到家人时按空格或按住空格，Ta 会跟着你
- **E**：钻进走廊地板上的避难所门
- 时间耗尽还没进避难所 = 灰飞烟灭

**取舍点**：水、罐头、收音机、猎枪、防毒面具、工具箱、急救包、药片、扑克牌、泰迪熊……
时间只够拿其中几件。而且你救不救家人，决定地堡里多一个人吃饭还是多一份绝望。

### 第二幕：15 天
地板门在头顶合上，剩下的是算术题。

每天的循环：**配给 → 广播与事件 → 派人外出（可选）→ 夜晚结算**

- **配给**：谁吃罐头、谁喝水，你自己决定。饿两天、渴两天会掉体力。
- **事件**：23 张事件牌——漏水、变异蟑螂、有人敲门、空投、征用、辐射风暴、门外是你没救下来的家人……
- **外出探险**：派一个人出去，可能带回三四罐口粮，也可能带不回自己。带下去的装备越齐（面具 / 手电 / 猎枪 / 地图），活着回来的概率越高。
- **消耗品**：在**早晨的配给环节**点「使用」生效（其他阶段按钮不显示）。每件东西的用途直接写在物品下面：

  | 物品 | 效果 |
  |---|---|
  | 🩹 急救包 | 治好「受伤」+ 最伤的人体力 +32 |
  | 💊 药片 | 治好「生病」+ 体力 +6 |
  | 🧸 泰迪熊 | 蒂米体力 +16；蒂米不在（没救下来 / 已遇难）就全家 +5 |
  | 🃏 扑克牌 | 全家人体力 +7 |
  | 🚬 香烟 | 最虚弱的人体力 +9 |
  | 🧼 香皂 | 全家人体力 +4 |
  | 🐟 金鱼 | 全家人体力 +5 |

  注意：饥饿 / 口渴只有**吃喝**能清掉，「🤕 受伤」「🤒 生病」只有**急救包 / 药片**能清掉，
  两者不能互相顶替。
- **撑过第 15 天**，救援队就会经过这片区域。

死法很多：泰德倒下 = 立即结束；全员遇难 = 结束；也有可能只剩你一个人爬出地堡。

## 操作一览

| 按键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动（也可以按住鼠标往一个方向跑） |
| `空格` | 抓取物资 / 让家人跟上 |
| `E` | 进入避难所 |
| `P` | 暂停 |
| 鼠标 | 点按钮 |

音效是实时合成的（Web Audio），右下角标题页可开关，设置记在 localStorage。

## 文件结构

```
index.html             ← 入口（引用 style.css + src/*.js）
style.css              ← 1950 年代印刷风 UI
src/game-core.js       ← 工具 / 音效合成 / 物品与家人数据 / 程序化房屋生成
src/game-scavenge.js   ← 第一幕：Canvas 抢物资（移动、碰撞、抓取、跟随、渲染）
src/game-bunker.js     ← 第二幕：配给、事件牌组、探险、夜晚、结局
src/game-ui.js         ← 屏幕状态机、地堡 DOM 渲染、结局文案、主循环
dev/smoke.js           ← 无浏览器冒烟测试（桩掉 DOM/Canvas）
dev/ui-check.js        ← 真实浏览器点击测试（headless Edge 点按钮，验事件委托）
dev/ui-check-negative.js ← 反向验证：故意把 bug 改回去，确认上面那个测试会失败
dev/build.js           ← 打包成单文件
dev/shots.js           ← headless Edge 截图（人眼检查画面）
```

> 单文件版 `60秒地堡余生.html` 是 `node dev/build.js` 的产物，按 `.gitignore` 不提交仓库
> （避免同一份代码两份真相），需要时本地生成即可。

## 开发命令

```bash
node dev/smoke.js                 # 逻辑测试（房屋连通性 / 60 秒判定 / 120 局地堡模拟）
node dev/build.js                 # 重新打包单文件
node dev/smoke.js 60秒地堡余生.html   # 对打包产物再跑一遍逻辑测试
node dev/ui-check.js              # 真浏览器点「使用」「配给」按钮（需要 Edge）
node dev/ui-check-negative.js     # 反向验证该测试确实有效
node dev/shots.js                 # 截图
```

> 教训：桩 DOM 只能测逻辑，测不到"事件委托挂在哪个节点"。地堡里消耗品的「使用」
> 按钮曾经因为委托只绑在 `#stage`（按钮在兄弟节点 `#inv` 里）而完全点不动，
> 所以现在补了一个真浏览器的点击测试。

冒烟测试里有个平衡性指标：让一个"机器人"随机选事件、天天派人外出，120 局里大约
一半能活到第 15 天；而从不外出的 21 局平均只撑到第 7 天——所以外面虽然危险，
但不出门是真的不行。
