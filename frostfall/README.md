# 永冬 · Frostfall

一个纯前端单页的《冰汽时代》（Frostpunk 1）风格**环形城市建造+生存**小游戏。
只做了第一代最核心的那条线：**围着发电机一圈圈盖城市、用热量把居民拖出死亡线**——
没有议会、没有派系、没有第二代的委员会投票。

**3D 场景**由 Three.js 实时渲染：低多边形建模、动态阴影、发电机热柱与暖光、
风雪粒子、昼夜与风暴光照。three.js 已内置在 `vendor/`，**完全离线**。

打开方式：**双击 `index.html`** 即可（不需要服务器、不需要构建、不需要联网）。

## 玩法

你有一座环形城市：中心是发电机，外面 **7 环 × 16 扇区** 共 112 块地。
23 天里气温从 -20°C 一路跌到 -70°C，第 20 天起还有三天**大风暴**。
熬到**第 23 天黎明**就算赢。

### 三条核心规则

1. **管网连通**：建筑必须和城市连起来才有效。
   第 1 环紧贴发电机，永远算连通；再往外，每块地都要和**已有建筑或道路相邻**。
   想往外扩，就得先铺路（选中远处的空地会出现「自动接通道路」）。
2. **供热**：发电机只给**供热范围**（默认 2 环，可研究到 4 环）内的建筑供热。
   范围外的建筑 = 气温直供，-40°C 时基本等于停工 + 生病。
   **蒸汽枢纽**能自己烧煤，为周围 3 环 × 3 区供热，是把城市铺到远处的关键。
3. **温度**：每个建筑有自己的温度 = 气温 + 供热增量。
   - `>= 0°C` 温暖，不生病
   - `< -5°C` 开始有人生病，病人**不上岗**
   - `< -20°C` 会**直接冻死人**（大风暴里最致命的一条）

### 生产与工人

工人**自动上岗**，优先级：煤矿 → 伙房 → 医疗站 → 工坊 → 猎人小屋 → 锯木厂 → 钢铁厂。
想腾工人就把某座建筑点「停工」。

| 建筑 | 作用 | 备注 |
|---|---|---|
| 煤矿 | 产煤 | **必须建在煤脉上** |
| 锯木厂 | 产木材 | **必须建在树林上** |
| 钢铁厂 | 产钢铁 | **必须建在铁矿上** |
| 猎人小屋 | 产出生食 | 不需要供暖，但严寒会掉效率 |
| 伙房 | 生食 → 餐食 | 每天全城吃 0.8 份/人 |
| 医疗站 | 治病 | 满编约 7 人/天 |
| 工坊 | 产出研究点 | 科技的唯一来源 |
| 帐篷 / 房屋 | 床位 20 / 26 | 房屋自带 +4°C |
| 蒸汽枢纽 | 远程供热 | 烧煤，覆盖 3×3 |

发电机的煤炭消耗按档位递增（3 / 5.5 / 9 / 14 每小时），**过载**再 ×1.6 但 +15°C，
压力攒满会炸炉停机 10 小时。

### 科技（14 项）

研究点来自工坊。主线是**供热**：管线延伸 → 楼宇加热器 → 隔热改造 → 发电机出力。
想活着过风暴，基本要把「发电机出力 II + 加热器 + 隔热改造」凑齐。

### 情绪

- **希望** 归零 → 居民弃城
- **不满** 满 100 → 暴动
- 温暖、吃饱 → 希望缓慢回升；寒冷、露宿、断粮 → 不满上涨

### 事件

固定在第 4 / 6 / 8 / 10 / 12 / 14 / 16 / 18 天有剧情事件（难民、请愿、疫病、发电机故障、风暴预警……），
另外每天有 22% 概率触发随机事件。每个事件两个选项，没有标准答案。

## 操作

| 操作 | 说明 |
|---|---|
| 左键 | 选择地块 / 放置建筑 |
| 左键拖拽（道路模式） | 连续铺路 |
| 左键拖拽（普通） | 拖动地图（地图跟着光标走，1:1） |
| 右键拖拽 | 拖动地图 |
| 滚轮 | 缩放（以光标为锚点，不跑偏） |
| `Q` / `E` | 旋转视角 |
| 右键 / `Esc` | 取消建造模式 / 取消选择 |
| `空格` | 暂停 |
| `1` `2` `3` | 速度 |
| `H` / `R` | 帮助 / 回到中心 |

`index.html#play` 可以跳过开始界面直接开局（调试用）。

## 目录

```
index.html            页面骨架
vendor/three.min.js   Three.js r149（UMD，离线内置）
css/style.css         界面样式
js/data.js            所有静态数据（建筑 / 科技 / 天气 / 事件）—— 调平衡先看这里
js/engine.js          纯逻辑模拟（无 DOM，可被 Node 加载）
js/render.js          3D 场景：相机 / 光照 / 建筑建模 / 粒子 / 拾取
js/ui.js              面板 / 弹窗 / 交互
js/main.js            启动与主循环
tools/sim.js          无头模拟：脚本 AI 打完一局，检查崩溃与数值
tools/cdp.js          CDP 驱动 headless Edge：注入操作 + 截图 + 收集 console 错误
tools/scenarios.js    cdp.js 的测试场景
```

`js/render.js` 里可以调的东西：`PLAZA` / `RING_W`（环形尺寸）、`MODELS`（每种建筑的低模造型）、
`initMaterials()`（材质配色）、`this.elev` / `this.azim`（相机俯角与朝向）、
各处 `PointLight` / `DirectionalLight` 的强度。
如果实测帧率低于 32fps，渲染器会**自动关掉阴影**保流畅。

数值集中在 `js/data.js`（`FW.CFG` / `FW.BLD` / `FW.TECHS` / `FW.WEATHER`）
和 `js/engine.js` 开头的 `COAL_BURN`、`coldIllness()`、`exposureRate()`、`stepMood()`。

跑平衡测试：

```bash
node tools/sim.js 20260217 normal    # easy / normal / hard
node tools/cdp.js play               # 需要 Edge，截图输出到 shots/
```
